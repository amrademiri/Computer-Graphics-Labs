Hand controls

Each finger has three connected segments. Its local joints bend relative to the previous segment, demonstrating hierarchical transforms.

Geometry hierarchy

Hand root ├─ Wrist ├─ Palm ├─ Thumb → 2 segments ├─ Index → 3 segments ├─ Middle → 3 segments ├─ Ring → 3 segments └─ Pinky → 3 segments
Orientation

Camera faces the palm; the thumb is explicitly constructed on the LEFT side. Drag to inspect the joint structure from multiple angles.
