Computer Graphics · Interactive portfolio

Five labs. Five different 3D experiments.

Open each self-contained lab to explore rotation, vectors, orbital transforms, an articulated hand, and indexed geometry.

01 / MOTION

Rotating Cube

Lighting, rotation speeds and camera orbit.

 02 / MATH

Vector Laboratory

Vector arithmetic, arrow visualization and ray–plane intersections.

 03 / HIERARCHY

Solar System

Earth with Moon and Mars with Phobos.

 04 / ANIMATION

Robotic Hand

Five digits, independently hinged segments and control sliders.

 05 / MESHES

BufferGeometry Shapes

Custom crystal and vase meshes built from indexed triangles.

Run locally: In the project folder, enter python3 -m http.server 8000 and open localhost:8000. Read README.md for GitHub commit steps and the Lab 2 rubric note.
